# S4 文案定稿与形态派生

## 目标

把 S3 定下的方案写成**能直接念、直接发**的文本。这一步的成品质量决定整条内容的上限——画面可以补，文案补不了。

## 主线结构

所有形态共用一条主线，四段：

| 段 | 作用 | 长度参考（60 秒视频） |
|---|---|---|
| 钩子 | 让人停下来 | 3 秒 / 两行 |
| 张力 | 让人想知道后面 | 5–8 秒 |
| 展开 | 给信息或故事 | 40 秒 |
| 落点 | 记住什么、做什么 | 5–8 秒 |

### 钩子的写法

从下面五种里选一种，不要混着用：

1. **具体场景**：直接扔进一个画面。"我被优化那天，HR 说了句让我记了三年的话。"
2. **反常识断言**：说一句会被反对的话。"劝你别把父母接到城里住。"
3. **代价**：把成本摊开。"这个错误让我赔了四万块，起因是一个我以为没人会看的条款。"
4. **原话引用**：直接放对话。"他跟我说，你这方案挺好，就是我们不用。"
5. **缺口**：说一半。"我删了公司三年积累的客户表，第二天老板请我吃饭。"

**必须避免的开场：** 自我介绍、感谢、交代背景、"今天想跟大家聊聊"、"最近有个感悟"。这些全是让人划走的地方。

### 展开的两种走法

- **故事线**：起因 → 卡住 → 转折 → 结果。适合私密自述、对话类起点。
- **信息线**：结论 → 为什么 → 怎么做 → 边界。适合信息差、工具类起点。

不要在一篇里同时走两条线，会散。

## 形态派生

主线定稿后，按 S3 选定的形态派生。**一次只派生一种**，其余留到需要时再说。

### 口播稿（视频）

- 一句一个意思。超过 25 个字就断句。
- 每 60–70 字一个信息点，约 15 秒。
- 禁书面连接词：然而、因此、综上所述、值得注意的是、不难发现。
- 停顿标记：`/` 短停，`//` 换气。
- 重音用 `**加粗**` 标出。
- 语速按每秒 4 到 4.5 字计算，反推总时长。
- 念一遍，卡住的地方就是句子有问题，改句子不要改语速。

### 图文（小红书 / 公众号）

- 每段一个观点，段落不超过四行。
- 配图位置标 `[图：具体内容]`，不要写"配一张相关图片"。
- 首图上的文字必须能独立成句，脱离正文也看得懂。
- 结尾留一个可回答的问题，不要留"欢迎讨论"。

### 播客

- 写提纲不写逐字稿，逐字稿会念得像朗读。
- 每段给三个关键词 + 一个必须讲到的例子，其余靠即兴。
- 标注预计时长和可以剪掉的段落。

### 博客

- 小标题要能单独串起来读懂全文。
- 首段给出结论，不要卖关子——搜索来的人没耐心。
- 每 300 字左右一个小标题，便于扫读。

### 海报

- 主标题 ≤ 12 字，必须是主张，不是主题。
- 副文案最多 3 行，每行 ≤ 18 字。
- 必须有行动指引（扫码 / 时间地点 / 关注）。
- 留白比信息重要，一张海报只讲一件事。

## 去 AI 味四关

文案写完必须自检，不过不改。规则见 `de-ai-flavor` 技能，四关：

1. **主语清晰**：每句都知道是谁在做。警惕"通过……使得……"这类无主句。
2. **的 不省**：该有的"的"要留着，省掉会变成名词堆叠。
3. **双字到位**：单字词换成双字词——"做"改"做出"、"看"改"看到"、"想"改"想到"（视语境）。
4. **朗读通顺**：出声念一遍，气不够、绕舌头、需要回看的句子全部重写。

**高危信号清单**，出现即改：

- 三段式排比连用（"不是……而是……更是……"）
- 空词堆叠：赋能、抓手、闭环、底层逻辑、认知升级
- 每段结尾都要升华一句
- 「在这个……的时代」开头
- 通篇没有一个具体的人名、数字、地点、时间

## 产出格式

写 `05-script.md`：

```markdown
# S4 文案定稿

## 主线文案
### 钩子
### 张力
### 展开
### 落点

## <形态> 派生稿
<按选定形态的规范写>

## 自检
- [ ] 钩子不属于五种禁用的开场
- [ ] 主张能被反对
- [ ] 有四关自检通过
- [ ] 高危信号零命中
- [ ] 字数/时长符合 S3 的方案规模
```

## 收尾

闸门问题通常一个：这条文案念出来，你自己会不会停一下。如果用户说"还行"，基本等于不行，追问哪里不行。

## 做好的标准

用户能不看稿复述出核心那一句。复述不出来，说明主线还不够锋利。
